# Healthcare-Predictive-Analytics
Machine Learning-based healthcare analytics project for predicting diabetes and heart disease risk using Python, Google Colab and Power BI.
# Healthcare Predictive Analytics – Diabetes & Heart Disease Prediction

It combines Python-based predictive modelling with interactive Power BI dashboards to explore healthcare data and communicate analytical insights.

## 🎯 Project Objectives
- Predict diabetes risk using patient health indicators.
- Predict heart disease risk using clinical attributes.
- Compare actual outcomes with model predictions.
- Explore important health factors associated with disease outcomes.
- Present insights through interactive Power BI dashboards.

## 🛠️ Tools & Technologies
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Power BI

## 📊 Project Modules

### 1. Diabetes Prediction
- Data preprocessing and exploratory data analysis.
- Machine Learning-based diabetes prediction.
- Analysis of glucose, BMI, blood pressure and age.
- Comparison of actual and predicted outcomes.

### 2. Heart Disease Prediction
- Data preprocessing and exploratory data analysis.
- Machine Learning-based heart disease prediction.
- Analysis of age, cholesterol, chest pain and other clinical attributes.
- Comparison of actual and predicted outcomes.

## 📈 Power BI Dashboard

The interactive dashboard contains three pages:

1. **Healthcare Overview** – Combined healthcare KPIs.
2. **Diabetes Analysis** – Diabetes-related metrics, charts and filters.
3. **Heart Disease Analysis** – Heart disease metrics, charts and filters.

## 🔍 Key Features
- Predictive analytics for two diseases.
- Interactive KPI cards and visualizations.
- Age and category-based filtering.
- Actual versus predicted outcome analysis.
- Data-driven healthcare insights.

## 📁 Project Deliverables
- Python / Google Colab notebooks.
- Prediction output datasets.
- Power BI dashboard.
- Project screenshots and documentation.
